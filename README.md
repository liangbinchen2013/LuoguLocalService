# LuoguChatNotify
Luogu 私信 Windows 系统桌面通知

## 项目简介

洛谷私信 Windows 原生桌面通知解决方案，基于 **油猴脚本 + Python 中转服务** 实现：
监听洛谷实时私信 WebSocket，转发到本地后台，弹出 Windows 系统通知；
支持一键安装、程序目录托管、开机自启、后台静默运行，轻量化低占用，只需浏览器常驻洛谷标签，即可实时接收私信弹窗提醒。

## 仓库文件说明
```
LuoguChatNotify/
├── LuoguNotifyServer.py     # 通知接收主服务，监听请求、弹出系统通知
├── LuoguNotifyProxy.py      # 中转转发服务，接收油猴 POST 数据
├── LuoguChatNotify.user.js  # 油猴脚本，监听洛谷私信 WebSocket 并转发至本地
├── AutoSetup.bat            # 一键安装配置脚本（管理员运行）
└── Uninstall.bat            # 一键卸载脚本，停止服务+清理自启+删除程序目录
```

## 功能特性
-  洛谷私信实时监听，Windows 原生系统弹窗通知
-  无多余测试消息，仅接收他人发给你的私信
-  一键部署，自动迁移程序到系统 ProgramFiles 目录
-  自动配置开机自启，后台无黑框静默运行
-  安装完毕自动删除安装脚本，目录整洁
-  完整卸载脚本，无残留清理服务与自启项
-  轻量低资源占用，不影响电脑日常使用

## 使用要求
1. 本地已安装 Python，并配置环境变量
2. 浏览器已安装 **Tampermonkey 油猴** 扩展
3. 安装后需**手动登录洛谷，保留标签后台常驻**（关闭标签则断开监听）

## 安装步骤
1. 下载本仓库全部文件，放在同一个文件夹
2. 右键 `AutoSetup.bat` → **以管理员身份运行**
3. 按提示手动安装 `LuoguChatNotify.user.js` 到油猴
4. 打开浏览器登录洛谷，保持标签不关闭、最小化后台挂着
5. 此后开机自动运行后台服务，有私信即刻弹窗提醒

## 运行原理

1. 油猴脚本挂载洛谷 WebSocket，实时监听私信广播
2. 收到非自身私信后，POST 发送到本地 127.0.0.1:8888
3. Python 中转服务接收数据，转发给通知主服务
4. 主服务调用 Windows 原生通知接口，弹出桌面提醒

## 卸载方式
进入系统程序目录：
`C:\Program Files\LuoguNotify`
运行 `Uninstall.bat` 即可：
- 终止所有 Python 后台服务
- 删除开机自启快捷方式
- 清空程序目录，无残留

## 注意事项
- 请勿关闭浏览器洛谷标签，否则 WebSocket 断开无法接收通知
- 首次安装必须**管理员身份**运行安装脚本
- 若防火墙拦截，允许 Python 本地网络访问即可
- 无需额外配置，安装后直接即用
