# Changelog

所有重要变更都会记录在此。

## [v1.0.0] - 2026-06-01

### Added

初始代码，实现：
```
  命令              说明
  --------------------------------------------------
  article          查看文章 <ID>
  articles         查看最新文章（可翻页选择）
  discuss          查看讨论帖 <ID>
  discusses        查看最新讨论（可翻页选择）
  exit             退出程序
  feed             查看犇犇动态
  help             显示帮助信息
  home             查看主页运势/动态
  login            登录洛谷
  logout           退出登录(清除Cookie)
  problem          查看题目预览 <PID>
  profile          查看用户资料 [UID]
  quit             退出程序
```
